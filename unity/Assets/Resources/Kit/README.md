# The racing kit goes here

Nothing in this folder is required. The game builds its own trackside
scenery out of primitives and looks right without any of it. What this
folder does is let you replace those stand-ins with real models by
dropping files in — no code change, no scene to edit.

## Where to get it

**Kenney — Racing Kit**, <https://kenney.nl/assets/racing-kit>

Public domain (CC0 1.0). No attribution required, no licence file to
ship, nothing to ask permission for. That is the entire reason this pack
was chosen over better-looking paid ones: the project stays something
anybody can clone and run.

Kenney's **Car Kit** (<https://kenney.nl/assets/car-kit>) is the same
licence and does contain an open-wheel formula car, which is worth
knowing — but the car in this game is generated by `CarView`, and
swapping it is a separate job from dressing the circuit.

## How to install it

1. Download and unzip the pack.
2. Put the models you want in **this folder**, named exactly as below.
3. Press Play. `TracksideBuilder` looks each name up with
   `Resources.Load` and uses the prefab if it is there.

`Resources.Load` returns null rather than throwing when a name is
missing, so a partial install is fine: whatever you have is used and
everything else falls back to a stand-in. You can add one board and
leave the rest.

## The names

Each one is a value of `MumuF1.PropKind`, so the mapping is the enum and
nothing else has to be kept in step with it.

| File name here  | What it is                | Kenney model to use            |
| --------------- | ------------------------- | ------------------------------ |
| `Conifer`       | roadside tree             | (from Nature Kit, also CC0)    |
| `Broadleaf`     | roadside tree             | (from Nature Kit, also CC0)    |
| `MarshalPost`   | marker panel on a pole    | `sign`, `signDirection`        |
| `Grandstand`    | raked seating with a roof | `tribune`, `tribuneCovered`    |
| `AdBoard`       | hoarding against the wall | `billboard`, `bannerLarge`     |
| `Flag`          | flag on a pole            | `flag`, `flagCheckers`         |
| `StartGantry`   | gantry over the line      | `gateLarge`, `bridge`          |

The Racing Kit has no trees — they are in Kenney's **Nature Kit**, CC0
as well, if you want them.

## What the models have to satisfy

- **Origin at the foot.** Everything is placed on the ground, so a model
  whose pivot is at its centre sinks half of itself into the verge.
- **+Z is the front.** Boards, flags and posts are turned to face the
  road by a yaw about +Y, and the yaw assumes the model looks along +Z.
- **Roughly the stand-in's size.** Placement leaves room for the
  stand-in — a hoarding 7 m wide and 1.4 m tall, a grandstand 26 m wide.
  A model much larger than that will reach places the tests say nothing
  reaches, because those tests measure the placement and not the model.

## What is not loaded from here

The barrier is swept from the road's own vertices rather than placed, so
it follows every corner exactly instead of being fitted alongside it. A
fence prefab repeated along a spline cannot do that without either
gapping on the outside of a corner or overlapping on the inside. If you
want the kit's fence look, change the colours in `TracksideBuilder`
rather than the geometry.
